API Documentation - Posting E-Invoice to GSTZen 
GSTZen E-Invoicing API works as follows. ERP system posts E-Invoice data to GSTZen and GSTZen posts it to the Govt Portal (IRP) with appropriate authentication and encryption and returns a response. This document describes how to post data and the response format.


GSTZen accepts data over a HTTP REST API. The ping API call is a GET method, the others are HTTP POST API calls.
Demo GSTIN
Sign up at https://my.gstzen.in to create an account. For the Demo purposes, please use any of the GSTINs provided in this link - https://www.gstzen.in/a/generate-e-invoice-api.html.


In the GSTZen account, click on E-Invoicing and click on Tally, SAP, or corresponding integration. Note down the Authentication token on this page. You will be using it to make API calls.

Consuming the Response
GSTZen provides a consistent response format for all E-Invoicing and E-Way Bill API calls. The key fields to notice, highlighted in yellow are
* message - Display this directly to the user in your application's user interface. GSTZen tries to provide a very meaningful message and we are improving this over time.
* status - status = 1 indicates success and status = 0 indicates failure. You can show show the message with an indication of success (such as a tick mark or green color) or of failure (such as cross mark or red color)
* IrnStatus - This field indicates the status of the E-Invoice. The possible values are
   * GEN for Generated
   * ERR for Error
   * CAN for Cancelled
   * NON for Not Generated
* EwbStatus - This field indicates the status of any E-Way Bill associated with the E-Invoice. The possible values are the same as that of IrnStatus.
* uuid - A unique identifier in GSTZen to identify the Invoice. You can use this to contact GSTZen Support if you have any issues with this particular invoice.


The salient feature of GSTZen's E-Invoicing API is that you handle responses for all API calls the same way. Whether you are trying to generate an E-Invoice, or cancel an E-Invoice, it does not matter if the operation succeeds or fails. As a developer, you only have to look at the IrnStatus and EwbStatus fields to know the status of the Invoice.


Or course there are other fields such as IRN, Signed QR Code, Signed Invoice, EWB Number and Date. You can save these details in your ERP.
